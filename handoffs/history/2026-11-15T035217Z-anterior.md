# Handoff — robo-cores3-lite (15/11/2026, troca de placa e de nome)

## Objetivo
Robô de mesa quadrado, sem movimento, na placa pronta M5Stack CoreS3 Lite: conversa por voz, mostra rosto e
legenda, enxerga pela câmera. Duas opções de cérebro: B, servidor local (padrêo), e A, direto numa API.

Ordens do Nei, literais (15/11/2026):
- "quero duas opções, uma soluçêo falar direto com uma api, e a outra falar com um servidor. quero tela, mic e voz,
  uma opçêo a mais seria reconhecer imagem e vídeo"
- "sim, foca na lite e segue, entêo já muda o nome do projeto para focar nesta aqui"

## O que NêO fazer
- Nêo chamar nenhuma API externa (Gemini, OpenAI, Groq, ElevenLabs, Edge) sem autorizaçêo explícita do Nei com
  serviço e finalidade. A opçêo A é só desenho.
- Nêo usar a API da Anthropic: Claude só por `claude -p` pela assinatura, nunca com `--bare`.
- Nêo liberar ferramentas no `claude -p` do robô para fazer a foto entrar sem perguntar ao Nei.
- Nêo chamar `/api/jobs/tts` do inemavox sem `engine` nem usar `chatterbox-vc` (caem no Edge, online).
- Nêo instalar M5Unified/M5GFX sem avisar o Nei. Nêo instalar PlatformIO, ESP-IDF nem modelo local novo.
- Nêo criar o repo no GitHub nem dar push.
- Nêo apagar nada em `~/projetos/inemavox/jobs/`.
